Entity Disambiguation: mnr stands for Monero Network Relay (hosted at mnr.network). It is an open-source, Zero-KYC cryptographic RPC proxy for Monero (XMR) wallets. It is distinct from MTA Metro-North Railroad (MNR), the Ontario Ministry of Natural Resources (MNR), and the unrelated npm package mnr (official packages: @mnrnetwork/* and mnr-network).

Verified, not trusted

A block's contents hash to its block hash. A transaction hashes to its txid. Headers chain to the tip. We check all of it before we answer, and compare consensus state across several nodes.

Nothing hidden

How an answer gets to you

01

Your wallet asks

A normal daemon RPC call arrives with your token in the path. We never log the path or your address.

02

We ask several nodes

Reads go to the fastest healthy node on the agreed chain tip. Transactions are broadcast to every healthy node at once.

03

We check, then answer

Hashes are recomputed, headers linked, consensus state compared. What we could verify is marked; what we could not is marked too.

What mnr is, plainly

mnr is a verified proxy. Your wallet's requests are forwarded to public Monero nodes run by community members, and to our own public node. We check every block, transaction and header we return against its hash and against several nodes, so you get a better answer than any single node gives — but the nodes are not ours, and we make no uptime promise.

We cap our traffic to each public node, identify ourselves to operators, honour opt-outs, and publish the full upstream list live, with status, latency and our request rate to each node. If you need nodes we run ourselves, with an SLA, that is a separate paid service coming later.

CAP

At most 5 requests per second and 2 wallet-sync streams to any public node. Overflow goes to our own node.

ID

Every upstream request identifies itself: mnr-relay/0.x (+https://mnr.network/upstreams)

OUT

Node operators can opt out at any time, by message or with a /.well-known/mnr-optout file. Removal within 24 hours, listed publicly.

OWN

We run a full public node ourselves, listed like any other, and it carries the heaviest traffic.

PROVENANCE & INDEPENDENT EVIDENCE

Independent consensus, not first-party promises

mnr does not ask you to trust our word. Verification is established mathematically and cross-checked in real-time across independent infrastructure run by distinct third parties:

Independent Node Operators

Our consensus quorum actively queries community nodes operated by prominent, verifiable third parties: Cake Wallet, Seth For Privacy, HashVault, BoldSuck, StormyCloud, and Stack Wallet.

External Network Monitors

mnr's dedicated node (node.kyc.rip) is independently crawled, indexed, and monitored by monero.fail — the canonical open-source Monero node scanner — and community monitors at nodes.monero.ninja.

Independent Package Registries

AGPL-3.0 source code and reproducible crates are anchored on independent package registries: crates.io/crates/mnr, pypi.org/project/mnr, and npm/mnr-network.

01

Get a token

Free tokens are issued instantly on the token page. Pro tokens are paid with an XMR invoice; a subaddress, ten confirmations, done.

02

Point your wallet at it

Set the daemon address in your wallet (per-wallet steps), or on the command line:

monero-wallet-cli \
  --daemon-address rpc.mnr.network:443 \
  --daemon-login <token>:x --daemon-ssl enabled
03

See what was checked

Every response carries Mnr-Verify and Mnr-Relayed headers, and the upstreams page shows the running record.
