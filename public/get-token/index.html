How Work Units (WU) are counted

      

        Monero RPC methods have radically different server costs. Checking the top height takes an in-memory scalar, while fetching ring decoys requires validating output indices and cross-referencing upstream nodes. We measure fair usage in Work Units:
      


      

        

          1 WU
          get_info / get_height
          Daemon status, top block height, network difficulty, and quorum checks.
        

        

          1 WU
          get_block_header
          Block headers fetched by height or hash; validated against parent hash tree.
        

        

          5 WU
          get_block
          Complete block payload with raw transactions; verified against block hash.
        

        

          10 WU
          get_outs (Decoys)
          Retrieval of ring decoy outputs; checked against consensus outputs.
        

      


      

        

          In practice: 500,000 WU is more than enough for regular wallet balance scanning and daily transactions across multiple devices. Allowances reset automatically at 00:00 UTC on the 1st of every month.

Authentication Invariant

        

          Stock Monero wallets authenticate using HTTP Digest; mnr extracts your bearer token from the Username slot and ignores the password (<token>:x). Light clients like Ripley Terminal use the path-token format (https://rpc.mnr.network/v1/<token>).
        

      

    


    
    

      
Frequently asked questions


      

        

          
Where do I input the token in my wallet?

          
In your wallet's Remote Node settings, set Host to rpc.mnr.network, Port to 443, check Use SSL, and enter your token in the Username / Daemon Login field. The password field can be anything (e.g. x).

        


        

          
What if I lose my token?

          
mnr stores only a one-way cryptographic hash (SHA-256) of your token for authentication. We cannot recover lost tokens. If you lose a Free token, simply generate a new one here in one click. If you purchase a Pro token, bookmark your unique invoice link.

        


        

          
How do renewals work?

          
When purchasing Pro, enter your existing sub_... token into the "Renew existing token" field before generating an invoice. Once the payment has the confirmations its amount needs (one to ten, by value), the expiration of your token is automatically extended.

        


        

          
Does mnr log IP addresses or transactions?

          
No. mnr operates under strict anti-surveillance principles: no IP logging, no path logging, and zero request payload persistence. Requests over Tor and I2P provide further transport layer anonymity.
